# Entry Law — Twin Peaks 2.0

**Authority:** Shane Warehime
**Scope:** All contributions to this repository, from any source

---

## §I — The Gate

Main is locked. No direct push. No agent commit. No automation merge.
Every change to main is a Pull Request reviewed and merged by Shane.
This is the structural law. It does not bend for urgency or convenience.

---

## §II — The Landing Pass

A contribution must earn a Landing Pass before Shane reviews it.
The Landing Pass is the .github/PULL_REQUEST_TEMPLATE.md checklist.
Every item must be satisfied. The contributor certifies this by checking each box.
Unchecked PRs are returned without review.

---

## §III — The Clean-Artifact Law

Every file committed to this repo is a clean artifact.

A clean artifact states what it is and contains only its intended content.
It is complete at the time of commit.

A clean artifact never contains:
- Notes to self or reminders
- TODOs, FIXMEs, TBDs, TKs, or deferred action items
- Process chatter, meta-commentary, or session narration
- Hedges, uncertainties, or unresolved questions
- Placeholder text left from drafting

Violations are grounds for PR rejection.

---

## §IV — The Gauntlet

All function content must pass the Gauntlet before entering this repo.
The Gauntlet is defined in README.md.
Work that has not passed the Gauntlet belongs in the staging repo (twin-peaks).

---

## §V — The Format Law

Every function lives in its own folder.
Every function folder contains exactly the four documents defined in
00_GOVERNANCE/FUNCTION_FOLDER_TEMPLATE.md — no more, no less, no deviation.

---

## §VI — Archive, Never Delete

Content is never deleted from this repo.
Superseded content is archived in place.
The archive record is preserved.

---

## §VII — Authority Order

1. Shane Warehime — sole merge authority, final decision on all content
2. Twin Peaks 2.0 Constitution (README.md) — governing document
3. This Entry Law — structural enforcement
4. 00_GOVERNANCE/CLEAN_ARTIFACT_LAW.md — quality gate
5. Browser Echo (BBB) — audit and guardrail hand; no merge authority
6. All other agents and contributors — execute within the above
