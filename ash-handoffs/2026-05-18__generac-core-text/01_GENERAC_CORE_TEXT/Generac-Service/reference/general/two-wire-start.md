# Two-wire start for air-cooled home standby generators

This article explains Generac's two-wire start feature, which generators are compatible with, how it works, who can install it, and addresses common questions regarding the two-wire start kit.

## Environment

This article applies to air-cooled home standby generators **10-28 kW with Nexus, Evolution, Power Zone 200 controllers** and the **7.5 kW PowerPact**.

## What is a two-wire start?

Two-wire start refers to a remote start feature available on Generac air-cooled home standby generators. This feature allows a Generac generator to be remotely started using other switch brands. Generac sells a kit that can be installed by a certified technician or end-user [(Part# 7109)](https://generac.ordertree.com/two-wire-start-kit/5638325796.p).

## How do I enable the two-wire start?

Enabling a two-wire start involves two main steps:

- Installing the two-wire start kit
- Programming the controller
  - **Note**: Programming the controller requires a dealer password for Evolution controllers. If performing this install on a generator with a [Power Zone 200 controller](https://support.generac.com/s/article/What-is-the-Power-Zone-200-Controller-for-Generac-home-standby-generators), you must have [dealer login access to Field Pro](https://support.generac.com/s/article/Permission-Levels-in-Field-Pro) to program the controller.

## What is the difference between a two-wire start and a remote start?

Nothing, they are used interchangeably to describe the starting function of some generators.

## Which generators support the two-wire start kit?

Remote start is available on all air-cooled and liquid-cooled units that feature a Power Zone 200, Nexus, Evo 1.0, Evo 2.0, Sync 2.0, or Sync 3.0 controller, including PowerPact units. However, not all LCD controllers (i.e., pre-Nexus controllers) have this feature.

The kit is not required on the EcoGen as it comes with two-wire start enabled from the factory. The EcoGen's 178 and 183 contacts are dry contacts used for two-wire starts. When the EcoGen receives a closed signal across these connections, the engine starts immediately. When that signal is opened the engine immediately shuts down.

The kit is also not needed on liquid-cooled units, as they already have the terminal blocks needed. However, to enable the feature, they will need to have the control panel programmed by a Generac-certified dealer. See [How Can I Find a Generac Service Dealer in My Area?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area)

## Can I install this kit myself?

- Completing the installation requires a dealer password for Evolution control panels.
- The PowerPact unit does not require a dealer password.
- If performing this install on a generator with a Power Zone 200 controller, you must have [dealer login access to Field Pro](https://support.generac.com/s/article/Permission-Levels-in-Field-Pro) to program the controller. If you do not have Advanced Access, [contact a local authorized dealer.](https://www.generac.com/dealer-locator/)

Generac recommends reaching out to a service dealer for these types of installations: See the [How Can I Find a Generac Service Dealer in My Area?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area) article for more information.

## Why would I need to enable a two-wire start?

This allows the generator to be used with a transfer switch with a two-wire start. The two-wire start feature is commonly employed in solar inverters and backup battery systems.

## Will enabling a two-wire start void my warranty?

Enabling two-wire start will not compromise the warranty, and using the generator with a non-Generac switch will also not compromise it. However, any damage to the generator caused by the switch, improper installation, misuse, etc., will not be covered under warranty. See [What Does My Home Standby Generator Warranty Cover?](https://support.generac.com/s/article/What-Does-My-Home-Standby-Generator-Warranty-Cover) for a complete description.

## Do any generators come factory-programmed for a two-wire start?

The EcoGen generator model is factory-programmed to work with a two-wire start system. In most applications, the EcoGen is controlled by an inverter. The inverter signals the EcoGen, using a two-wire start, when it needs to run.

## How do I set my generator for a two-wire start?

If using a non-EcoGen generator, a remote start kit must be purchased through a dealer. The kit comes with instructions on converting to a two-wire start and the additional wires required.

## What are wire terminals 178 and 183 or 395A and 395B used for?

Instructions to connect wires to the appropriate terminals on Power Zone 200, Evolution, Sync, and PowerPact controllers are included in the 2 Wire start instructions that come with the kit.

- 178 and 183 are the two-wire start control wires terminals on older generator series (Evolution and Sync controllers). These terminal connections will be hooked up to the transfer switch’s or inverter’s starting circuit. The generator will start when the controller receives a closed signal between these two wires. When the circuit is opened, the generator shuts down.
- 395A and 395B terminals are on the Next Generation Air-Cooled standby generator and are used for the Generator Emergency Shutdown Kit.
  - These terminals are utilized with the Aux Emergency Shutdown switch that can be installed on the generator. This is a separate shutdown button/switch used apart from the Generator Emergency Shutdown Switch located under the LED array. Model: **G0073620** **Generator Emergency Shutdown Kit.** If you need more information, we recommend you speak with an IASD.
- For more information about controller wiring, see: [What is the layout of the control wires and what do they do?](https://support.generac.com/s/article/What-Is-the-Purpose-of-Generac-Home-Standby-Generator-Control-Wires)
