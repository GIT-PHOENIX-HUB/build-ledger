# Engine cranks but will not start or runs rough

This article covers the most common issues but is not exhaustive. If these steps do not identify or resolve the issue, generator owners should reach out to a local authorized service dealer. See the [How Can I Find a Generac Service Dealer in My Area?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area) article for more information.

## Environment

This article applies to:

- Generac **Next Generation Series 10-28 kW air-cooled standby generators**
- Generac **Guardian Series****10-26 kW air-cooled generators** (2017 to present)

## Troubleshooting

**1\. Check [Mobile Link](https://app.mobilelinkgen.com/) or the generator control panel for error codes**

- When a generator isn't working properly, the issue is often indicated by an error code. Depending on the generator model, error codes are visible in different places:
  - For **Guardian series** generators, error codes can be observed on the generator's control panel, or in [Mobile Link.](https://app.mobilelinkgen.com/)
  - For **Next Generation series** generators, error codes can be observed in [Mobile Link](https://app.mobilelinkgen.com/) or Field Pro: [What is the Field Pro app?](https://support.generac.com/s/article/What-is-the-Field-Pro-app)

- Evaluate the cause of the error code whether it can be resolved by end users: [Where can I find a list of error codes for my generator?](https://support.generac.com/s/article/Where-can-I-find-a-list-of-error-codes-for-my-generator)
- Try clearing the error code and restarting the generator: See the [How Do I Clear an Error or Alarm Code On My Home Standby Generator?](https://support.generac.com/s/article/How-Do-I-Clear-an-Error-On-My-Home-Standby-Generator) article for more information.
- If the error code returns after clearing it, and restarting the generator, service from a [Generac authorized service dealer](https://www.generac.com/home-standby-generators/home-dealer-locator/) is required: [How Do I Request A Service Call For My Home Standby Generator?](https://support.generac.com/s/article/How-Do-I-Request-A-Service-Call-For-My-Home-Standby-Generator)

**2\. Was the unit recently installed?**

> **Note:** These steps should be performed by an [IASD](https://support.generac.com/s/article/What-Is-a-Generac-Independent-Authorized-Service-Dealer-IASD).

- Ensure fuel is turned on. A shutoff valve should be within 6 feet of the unit.
- Verify fuel lines have been bled. Air pockets in the line will prevent the unit from starting. This is **especially common if LP was recently refilled.**
- Check for an empty or low LP tank.
- Verify proper fuel conversion if running on LP.

**3\. Is this an existing install? When was maintenance last completed?**

- If running on LP, check for an empty or low tank.
- Verify appropriate maintenance is complete: [Where Can I Find the Maintenance Schedule for My Generac Home Standby Generator?](https://support.generac.com/s/article/Where-Can-I-Find-the-Maintenance-Schedule-for-My-Generac-Home-Standby-Generator)
- Check the air filter. See the [How Do I Check and Change the Air Filter On My Home Standby Generator?](https://support.generac.com/s/article/How-Do-I-Check-and-Change-the-Air-Filter-On-My-Home-Standby-Generator) article for more information.
- Check spark plugs. See the [How Do I Service the Spark Plugs in a Generac Air-Cooled Home Standby Generator?](https://support.generac.com/s/article/How-Do-I-Service-the-Spark-Plugs-in-a-Generac-Air-Cooled-Home-Standby-Generator) for more information.
- Check and change the oil and filter if necessary. See the [How Do I Change the Oil and Oil Filter in a Generac Air-Cooled Home Standby Generator?](https://support.generac.com/s/article/How-Do-I-Change-the-Oil-and-Oil-Filter-in-a-Generac-Air-Cooled-Home-Standby-Generator) article for more information.
- Ensure valve adjustments have been done at proper intervals. Valve adjustment procedures can be found in the generator's user manual. See the [How Do I Find a Copy of My Home Standby Generator Owner's Manual and Spec Sheets?](https://support.generac.com/s/article/How-Do-I-Find-a-Copy-of-My-Home-Standby-Generator-Owner-s-Manual-and-Spec-Sheets) for more information.

To schedule an inspection or service call, contact your local Generac authorized service dealer. See the [Where Can I Find a Generac Dealer in the U.S. Or Canada?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area) article for more information.
