# Home standby generator message codes

Error codes, also known as "alarm codes," indicate the status or an issue with the operation of a home standby generator. Some can be addressed and resolved by the end user, others will require the attention of a Generac service dealer. This article offers an overview of generator messaging that may be displayed in Mobile Link or on your generator control panel.

> **Note**: If the generator is enrolled within a Mobile Link account. You can see the error code number via the app under your [status history](https://support.generac.com/s/article/Mobile-Link-Generator-Statuses).

## Alarms and warnings facts

- Many yellow light error codes can be addressed by the end user/consumer
- Red light error codes may allow some initial troubleshooting, but will often require a visit from a Generac authorized service dealer if the code returns after attempting to address and clear the error.
- To find a list of error codes that **require the attention of a Generac service dealer** (not resolvable by the end user), see the [What Error Codes Do I Need to Call a Dealer For?](https://support.generac.com/s/article/What-Error-Codes-Do-I-Need-to-Call-a-Dealer-For) article for more information.
- To learn more about the meaning of error codes based on the **color of the generator's status LED**, see the [What Do the Green, Yellow, Blue and Red Status Indicator Lights Mean on Home Standby Generators?](https://support.generac.com/s/article/What-Do-the-Green-Yellow-and-Red-Status-Indicator-Lights-Mean-on-Home-Standby-Generators) article for more information.

What is the difference between maintenance reminders, warnings, and alarms?

Generator messaging is broken down into three categories: Alarms, warnings, and maintenance reminders. Alarm codes will display either a red or yellow indicator light. Warnings and maintenance reminders will also display LED statuses. For more information about the differences between alarms, warnings, and maintenance reminders, see: [What is the difference between maintenance reminders, warnings, and alarms?](https://support.generac.com/s/article/What-is-the-difference-between-maintenance-reminders-warnings-and-alarms)

> **Tip**: While some alarms and maintenance reminders can be dismissed, **a warning must be resolved** before the message will clear.

## Environment

This article applies to Generac air-cooled (AC) and liquid-cooled (LC) home standby generators. Note that where the error is displayed will vary depending on your generator's controller type:

- **[Evolution series](https://support.generac.com/s/article/What-is-the-Evolution-Control-Panel-for-Home-Standby-Generators):** These controllers have an LCD display. Error codes can be viewed on the LCD display or within Mobile Link.
- **[Power Zone 200:](https://support.generac.com/s/article/What-is-the-Power-Zone-200-Controller-for-Generac-home-standby-generators)** These controllers do not have a display. Error messages can only be viewed in the Mobile Link app. Mobile Link displays both the message and the numeric code.

## What if I don't see my specific code?

If you don't see your specific code, try referencing an article about a code with the **first two digits** of the code you're seeing. For example, if an article exists for 1500, that article generally applies to all variants of that code (1501, 1505, etc.) Some codes indicate issues that cannot be resolved by an end user and require a dealer visit: [What Error Codes Do I Need to Call a Dealer For?](https://support.generac.com/s/article/What-Error-Codes-Do-I-Need-to-Call-a-Dealer-For)To find a service dealer in your area, [see here.](https://www.generac.com/home-standby-generators/dealer-locator/?utm_source=helpcenter&utm_medium=article&utm_campaign=kbreferals&utm_term=helparticle)

> **Note**: Most error codes can be found in the owner's manual. To locate an owner's manual for a specific generator, [see here.](https://www.generac.com/support/product-info-user-manuals/)
