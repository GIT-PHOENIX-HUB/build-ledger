## What Does a 1063 Error Code Mean on My Home Standby Generator?

## 1063 indicates a Variable Speed Constant Frequency (VSCF) mismatch. A hard reset can be attempted, but if the issue persists, a certified service technician will need to inspect the system.      - Apr 18, 2024 - Knowledge

Title

What Does a 1063 Error Code Mean on My Home Standby Generator?

URL Name

What-Does-a-1063-Error-Code-Mean-on-My-Home-Standby-Generator

### Content

Public Answer

1063 indicates a Variable Speed Constant Frequency (VSCF) mismatch. A hard reset can be attempted, but if the issue persists, a certified service technician will need to inspect the system.
