# Transfer Switch Options -- Residential Generac

**Source:** Compiled from Generac transfer switch resources, scraped 2026-04-14.

## Transfer Switch Types

Generac offers two main categories of residential transfer switches:

### 1. Load Center Transfer Switch (16-Circuit)

- **Model:** RXG16EZA3 (current) / RXG16EZA1 (prior)
- **Rating:** 100A, NEMA 3R
- **Type:** Pre-wired 16-circuit load center
- **How it works:** Only designated circuits receive backup power. Homeowner
  selects which 16 circuits matter most.
- **Best for:** Smaller generators (10-18kW) where whole-house backup is not
  needed or budget is a factor.
- **Included with:** Generator + 16-circuit kit bundles (e.g., 7172, 7224)

### 2. Smart Switch / Service Entrance Rated (Whole House)

- **Model:** RXSW200A3 / RXG200A
- **Rating:** 200A, service entrance rated
- **Type:** Automatic whole-house transfer switch with load management
- **How it works:** Manages the entire panel. Built-in load shedding
  prioritizes critical circuits and sheds non-essential loads when demand
  exceeds generator capacity.
- **Best for:** Larger generators (18-28kW) and homeowners who want seamless
  whole-house backup.
- **Included with:** Generator + whole-house kit bundles (e.g., 7043, 7210, 7225, 7228, 7328)

## Comparison Table

| Feature | 16-Circuit (RXG16EZA3) | Smart Switch (RXSW200A3) |
|---------|----------------------|------------------------|
| Amperage | 100A | 200A |
| Coverage | Selected circuits only | Whole house |
| Load Management | No | Yes (automatic shedding) |
| Enclosure | NEMA 3R (outdoor rated) | NEMA 3R |
| Installation | Separate from main panel | Replaces main panel breaker |
| Generator Compatibility | 10-24kW | 14-28kW |
| Typical Price (with gen) | +$600-700 vs. unit only | +$800-900 vs. unit only |

## Key Installation Notes

- Transfer switch must match or exceed the generator's output amperage.
- Service entrance rated switches require coordination with the utility company.
- 16-circuit switches are installed alongside the existing panel.
- The Smart Switch replaces the main breaker position -- requires a licensed electrician.
- All Generac transfer switches are UL listed for automatic operation.
