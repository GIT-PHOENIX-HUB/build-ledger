# Warranty and Mobile Link -- Generac Guardian Series

**Source:** Compiled from Generac warranty and Mobile Link resources, scraped 2026-04-14.

## Warranty Coverage

### Standard Warranty -- Guardian Series Air-Cooled

- **Duration:** 5-year limited warranty
- **Coverage:** Defects in materials and workmanship
- **Starts:** Date of installation (or 18 months from manufacture if no
  installation date is registered)
- **Registration required:** Yes -- must be registered at register.generac.com
  within 30 days of installation

### What Is Covered

- Generator engine and alternator
- Control panel and electronics
- Enclosure
- Transfer switch (when sold as part of a bundled kit)

### What Is NOT Covered

- Normal wear items (battery, air filter, spark plugs, oil)
- Damage from improper installation
- Damage from power surges or lightning
- Units not installed by an authorized dealer
- Cosmetic damage

### Extended Warranty

Generac offers extended warranty plans through authorized dealers. Contact
Generac directly or check with the dealer network for current options.

## Mobile Link Remote Monitoring

### What Is Mobile Link?

Mobile Link is Generac's WiFi-connected remote monitoring system. It comes
**FREE** with every Guardian Series home standby generator.

### Features

- **Real-time status** -- See if the generator is running, in standby, or has a fault.
- **Exercise schedule** -- Set and modify the weekly exercise schedule remotely.
- **Maintenance alerts** -- Get notified when oil changes, filter replacements,
  or other maintenance is due.
- **Run history** -- Track how many hours the generator has run and when.
- **Fault alerts** -- Immediate notification if the generator reports an error code.
- **Dealer connection** -- Link your unit to an authorized service dealer for
  proactive service.

### Setup Process

1. **Create account** at app.mobilelinkgen.com or download the Mobile Link app.
2. **Connect generator to WiFi** -- Use the Evolution controller menu to enter
   WiFi credentials (generator must be within range of home WiFi).
3. **Register the generator** -- Enter the serial number in the Mobile Link app.
4. **Activate monitoring** -- The generator will begin reporting status within minutes.

### Mobile Link and Warranty

Registering and activating Mobile Link helps protect the warranty:
- Provides documentation of installation date.
- Tracks maintenance intervals (supports warranty claims).
- Enables proactive service alerts through connected dealers.

### Connectivity Options

- **WiFi** -- Standard on all current Guardian Series models (built into Evolution controller).
- **Cellular** -- Available as an add-on accessory for locations without reliable WiFi.
