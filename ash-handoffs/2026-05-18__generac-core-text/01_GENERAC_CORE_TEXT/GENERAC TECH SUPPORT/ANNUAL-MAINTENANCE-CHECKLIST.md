# Annual Maintenance Service Checklist

**Applies to:** Guardian 10–26 kW and Next Generation 10–28 kW air-cooled standby generators
**Owner:** Phoenix Electric LLC
**Service type:** Yearly / Schedule A / Schedule B

---

## Before You Start

### Safety
- Unit must be in **OFF** mode before service
- Turn **MLCB (Main Line Circuit Breaker)** to OFF
- Remove **7.5A fuse** from controller
- Wait for engine to cool if it was running
- **T1 fuse is ALWAYS under 120V even when generator is off** — exercise caution

### Tools Required
- 10mm wrench
- 3/8" drive socket
- Torque wrench
- Spark plug gap gauge
- Oil drain pan
- Clean rags/shop towels
- Multimeter (for battery and voltage checks)

### Oil Spec
- **Generac 5W-20 full synthetic oil** — recommended for ALL temperatures
- Oil capacity (with filter):
  - 10 kW Guardian: ~1.1 qt (1.03 L)
  - 14/18 kW Guardian: ~2.2 qt (2.1 L)
  - 20–26 kW Guardian: ~1.9 qt (1.8 L)
  - 10 kW Next Gen: ~1.4 qt (1.3 L)
  - 14/18 kW Next Gen: ~2.5 qt (2.4 L)
  - 22–28 kW Next Gen: ~2.2 qt (2.1 L)

## Service Checklist

### 1. Visual Inspection
- [ ] Check enclosure for physical damage
- [ ] Inspect louvers/vents for dirt, debris, rodent nests
- [ ] Check for water intrusion signs inside enclosure
- [ ] Inspect base/pad for settling or shifting
- [ ] Check corrosion — note any rust or paint damage
- [ ] Verify adequate clearance around unit per install specs

### 2. Battery Inspection
- [ ] Check battery terminals — clean corrosion if present
- [ ] Verify connections are tight
- [ ] Check battery voltage with multimeter (should read 12.6V+ when charged)
- [ ] Check battery condition on controller display or Mobile Link
  - "Good" = OK, let it charge
  - "Inspect Battery" = test further or replace
- [ ] Load test battery if voltage is marginal

### 3. Oil Change
- [ ] Start unit in MANUAL mode, run 3-5 minutes to warm oil
- [ ] Press OFF, wait 5 minutes for cooling
- [ ] Remove front panel
- [ ] Pull oil drain hose from retaining clip
- [ ] Drain oil into pan (note: milky sheen is normal)
- [ ] Reinstall drain cap and secure hose to clip
- [ ] Remove old oil filter (turn counterclockwise)
- [ ] Apply thin coat of clean oil to new filter gasket
- [ ] Hand-tighten new filter until gasket contacts adapter
- [ ] Tighten additional 3/4 to 1 full turn — **confirm tight**
- [ ] Fill with correct amount of Generac 5W-20 synthetic
- [ ] Start in MANUAL, run 1 minute, check for leaks
- [ ] Press OFF, wait 5 minutes
- [ ] Check oil level with dipstick — **DO NOT OVERFILL**
- [ ] Top off if needed, replace dipstick/fill cap

### 4. Air Filter
- [ ] Inspect air filter — replace if dirty or damaged
- [ ] Verify air box is sealed properly after reinstall

### 5. Spark Plugs (Schedule B / every 400 hours / 4 years)
- [ ] Remove and inspect spark plugs
- [ ] Check gap with spark plug gauge
- [ ] Replace if worn, fouled, or at Schedule B interval
- [ ] Torque to spec per owner's manual

### 6. Valve Adjustment (Schedule B — if applicable)
- [ ] **Does NOT apply to engines with hydraulic lifters**
- [ ] Adjust valves per owner's manual spec
- [ ] At 400 hours, valves almost certainly need adjustment
- [ ] **If unsure about valve adjustment, escalate to Shane**

### 7. Fuel System
- [ ] Perform fuel system leak test
- [ ] Inspect fuel lines and connections
- [ ] Check/clean sediment trap (if equipped)
- [ ] Verify fuel selector knob is on correct fuel type

### 8. Transfer Switch Inspection
- [ ] Visual inspection of ATS enclosure
- [ ] Check for loose connections
- [ ] Verify proper operation (utility/generator switching)
- [ ] Check for signs of overheating or arcing

## Post-Maintenance Procedure

### Return to AUTO — Normal Conditions (Utility Present)
1. Reinstall front panel and intake side panel
2. Reinstall **7.5A fuse** in controller
3. Complete Install Wizard if prompted (battery was disconnected)
4. Press **AUTO** button
5. Confirm **GREEN status light** is on
6. Set **MLCB to ON (CLOSED)**
7. Close and lock lid
8. Verify "READY TO RUN" on display (Guardian) or green status (Next Gen)

### Return to AUTO — During Utility Outage
1. Reinstall panels, fuse
2. Complete Install Wizard if prompted
3. Press **AUTO** — unit will start (MLCB still OFF)
4. Let run 1 minute with no load
5. Set **MLCB to ON** — generator now powering house
6. Unit will auto-shutdown when utility returns

### Clear Maintenance Reminder
**Guardian (Evolution controller):**
1. Press RED **OFF** button
2. Press **ENTER** twice for each maintenance alarm
3. Press GREEN **AUTO** button

**Next Generation:**
1. Press and hold **OFF** for 3 seconds, OR
2. Clear via Mobile Link app → "Clear Maintenance"

### Post-Service Checks
- [ ] GREEN status light confirmed
- [ ] MLCB is ON
- [ ] Battery connected and charging
- [ ] No active alarms on display
- [ ] Exercise schedule still set correctly
- [ ] Wi-Fi/Mobile Link still connected (reconnect if battery was pulled)

## Oil Change Triggers
- After first 25 hours (break-in period)
- Every 200 hours of run time
- Every 2 years minimum (regardless of hours)
- Every 100 hours in extreme temperature environments
- Every 24 hours during continuous-use outage (check level)
