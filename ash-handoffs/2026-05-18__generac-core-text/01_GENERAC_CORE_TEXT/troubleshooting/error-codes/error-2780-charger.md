# Charger missing AC code 2780

Home standby generator control panels may display the Charger Missing AC Code 2780 alarm code when there is an issue with the voltage at the T1 wire.

**Warning:** **Generac does NOT recommend end users attempt to modify or service internal generator wiring or attempt to service the transfer switch: [How Can I Find a Generac Service Dealer in My Area?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area)**

Generac-authorized service dealers are trained to resolve these issues and can be contacted using the [dealer lookup tool](https://www.generac.com/home-standby-generators/dealer-locator/) on Generac.com.

## Environment

This error can occur on Generac home standby generators. On **Guardian series** generators, the error will display on the **controller**. On the **Next Generation Air-Cooled Standby** series, the error will display **in Mobile Link**.

## Overview

**Error code**: 2780

**LED Indicator**: Yellow

**Fault**: CHARGER MISSING AC

**Issue**: This error indicates that the T1 wire is not receiving 120 VAC. This could be due an issue with the T1 wire, or the T1 fuse.

## Scenarios

### When in an active outage when the unit is running

This can occur if the automatic transfer switch did not transfer to standby when utility is lost. Check to make sure [the MLCB is set to ON](https://support.generac.com/s/article/What-is-the-generator-main-line-circuit-breaker-MLCB). For more information, see: [Troubleshooting Automatic transfer switch issues](https://support.generac.com/s/article/Home-standby-generator-power-transfer-issues-Troubleshooting-the-Automatic-Transfer-Switch)

### Not during an active outage

- Using a multimeter, a qualified technician can check to confirm the voltage received on the T1 wire. It should be receiving 120 VAC.
- Additionally, a qualified technician can inspect the T1 fuse inside the transfer switch to see if it has blown. If it is blown, a qualified technician can replace it using the supplied fuse puller: **[How Can I Find a Generac Service Dealer in My Area?](https://support.generac.com/s/article/How-Can-I-Find-a-Generac-Service-Dealer-in-My-Area)**

If the Charger Missing AC Code 2780 does not clear from the generator's control panel, the issue is not resolved. When the issue is resolved, the code will clear automatically.
